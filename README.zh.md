## 深度学习导论
这里我不会讲很多高深概念，严谨逻辑--这些市面上的教程做的很好了，我更多的是谈谈个人的理解，也许能帮助大家更好的理解深度学习。
深度学习本质上是拟合一个`函数`，也就是说很多事情都可以被某种函数描述出来，但和我们平常见到的函数不一样的是，深度学习拟合出来的函数是多元的，变量均是张量，并且复杂好几个数量级。
有了这样的宏观概念，我们能更好的知道哪些模块是重要的，哪些功能是需要重点关注的。

## 线性代数与深度学习
线性代数并不是某种很高深的领域，你可以把线性代数看作一个`信息`携带的载体，而深度学习中最重要的概念之一就是信息，如何在单位空间内携带更多的信息，是一个相当重要的课题。举个例子，如果一个矩阵是奇异矩阵，那么它不可逆，它就是一个`坏矩阵`(引自MIT 18.06 Gilbert Strang)，因为这个矩阵携带了一些`废话`。如果你不知道奇异矩阵是什么，没关系，大家应该都学过二元一次方程组:
```{2x+4=2y,4x+8=4y}```
很显然，这两个方程无法解出唯一解，因为第二个方程就是第一个方程的二倍，因此我们说这个方程携带的信息不够多。
